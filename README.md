#  Bike Sales Dashboard

This project is an interactive Excel dashboard that analyzes bike sales based on various customer demographics and behaviors. It provides visual insights to help understand what factors influence bike purchases.

##  Dashboard Features

- **Average Income Per Purchase**: Shows income differences by gender and bike purchase status.
- **Customer Age Brackets**: Compares purchasing behavior across adolescent, middle-aged, and older customers.
- **Customer Commute**: Analyzes how distance from home to work affects bike buying decisions.
- **Interactive Slicers**:
  - Marital Status
  - Region (Europe, North America, Pacific)
  - Education Level
  - Age Brackets
  - Gender

##  Tools Used

- Microsoft Excel
- Pivot Tables & Charts
- Slicers (interactive filters)
- Data cleaning and structuring

## 📈 Insights

- **Middle-aged customers** are the most likely to purchase bikes.
- **Higher income** is generally associated with bike purchases.
- **Shorter commute distances** tend to lead to more purchases.
- **Males** show slightly higher purchase rates and average income than females.
